# 虚空图书馆

本地 Electron 桌面应用，用于管理娱乐收藏、通关记录、目标、截图、角色图集，以及带嵌套系列的电子书书架。支持本地阅读、在线搜索图片和备份导入导出。

## 本次重构

2026-10-12 对照原软件包完成代码梳理和模块化重构。保留应用功能、界面样式、预加载接口、存储格式及第三方阅读器资源；应用版本仍为 2.0.0，使用原有 Electron 44.5.1 运行时和锁定的开发依赖。本次升级针对代码组织、重复实现、导入内存占用和工程验证流程，不是运行时版本升级。

- 主入口从 2,185 行整理为 52 行，将文件存储、书籍导入、阅读服务、刮削、IPC、协议处理拆到独立模块。
- 界面脚本从 4,430 行整理为 4,028 行，提取工具、数据规范化和图表模块。页面交互仍由 `renderer.js` 协调。
- 统一封面、角色和截图的图片写入逻辑，以及 JSON 临时文件替换逻辑。
- 文件夹图片导入共用一个实现，通过 `copyFile` 复制，避免在 JavaScript 中缓存整个图片文件。
- ZIP 测试直接调用正式模块，移除通过字符串截取生产源码再执行的测试方式。
- 增加后端集成测试、语法检查、打包文件逐字节校验和真实 Electron 启动检查。


## 阅读器性能重构（2026-10-12）

本版继续在现有书库数据、界面与功能契约下优化阅读器：电子书改为 HTTP Range 按需读取，正常 EPUB 跳过全量重压缩，需修复且超过 64 MiB 的 EPUB 使用临时磁盘缓存；ZIP/CBZ 漫画按页解压，TXT 在多帧内创建文本节点，iframe 启动前同步字号、主题、布局和断点。

代码审查、模块级基准、测试结果、已知限制及 Windows 人工验收步骤见 [`docs/reader-refactor-report.md`](docs/reader-refactor-report.md)。执行 `node scripts/benchmark-comic.cjs`、`node scripts/benchmark-reader.cjs` 可重测。

## 阅读器第二轮优化（单双页 / 滚轮 / PDF）

新增「单页 / 双页」按钮，支持 EPUB 等电子书、PDF 固定版式、CBZ/ZIP 等漫画图片页。消除滚轮 260ms 和底层翻页 100ms 人为等待；在内嵌内容 iframe 中单独处理滚轮输入。PDF 实现首屏优先显示画布、延后构建文字批注层、近期页面位图缓存、并发加载及双缓冲替换，降低重复渲染与切换闪白。原有文本选择、目录、阅读进度及书籍格式不变。

详细记录和 Windows 尚待验证的项目见 [`docs/reader-v2-report.md`](docs/reader-v2-report.md)。新增专项回归位于 `test/reader-interactions.test.js`。

## V3 与 V4 阅读器维护

V3 修复缩放后滚轮滚动和导入书籍相对路径。V4 新增固定整数页码跳转、书签管理、大小重置与首尾不循环。EPUB 等流式电子书的数字页码使用阅读位置编号，真实 PDF 等固定版式为精确页码。详见 [`docs/reader-v4-report.md`](docs/reader-v4-report.md)。

## 运行与验证

在本目录运行，开发工具已在 Node.js 24.18.1 验证。全新环境可用 `npm ci` 按锁文件安装开发依赖。

```powershell
npm run check
npm test
npm run build:portable
npm run smoke
```

`npm run build` 只生成 `dist/app.asar` 和 SHA-256 清单 `dist/manifest.json`。`build:portable` 默认从同级 `虚空图书馆-win32-x64` 复制运行时，生成 `dist/虚空图书馆-重构版-win32-x64/虚空图书馆.exe`。运行时目录可通过 `VOID_LIBRARY_RUNTIME` 指定。

构建只复制明确列出的运行时文件、语言资源及新的应用包，不复制原软件的收藏、书籍、图片或 API 密钥。独立重构版首次启动使用自己的数据目录，因此会显示原有的示例记录。`npm run smoke` 会短暂启动该软件，使用临时用户配置和数据目录，检查后自动退出并清理临时目录。

构建命令本身不自动运行测试；修改源码后应按上面顺序检查、测试、打包、启动验证。不要在重构版正在运行时重新覆盖其应用包。

## 模块位置

| 位置 | 职责 |
| --- | --- |
| `app/main.js` | 组装模块、创建窗口和应用生命周期 |
| `app/lib/paths.js` | 原有便携目录优先策略及目录初始化 |
| `app/lib/collection-store.js` | 收藏、角色、资料集和设置，包含旧数据迁移 |
| `app/lib/library-store.js` | 书架保存、文件及文件夹导入、漫画解包 |
| `app/lib/image-store.js`、`json-store.js` | 共用图片读写、清理、复制和 JSON 写入 |
| `app/lib/zip.js`、`media.js`、`dates.js` | ZIP、媒体路径编码和年份转换 |
| `app/lib/art-reader.js`、`book-server.js` | 图片浏览、封面提取、回环阅读服务和 EPUB 修复 |
| `app/lib/scrapers.js` | 翻译、图片搜索、作品和角色刮削；可注入网络请求进行测试 |
| `app/lib/ipc.js`、`protocols.js` | 保持现有 IPC 和媒体协议契约 |
| `app/preload.js` | 原有 `window.voidLibrary` 桥接接口，内容未变 |
| `app/src/utils.js`、`models.js`、`charts.js` | 界面共用逻辑、记录规范化、统计图表 |
| `app/src/renderer.js` | 页面状态、筛选、弹窗、阅读器交互和事件绑定 |
| `app/book/vendor`、`app/src/pinyin-pro.js` | 包含原第三方资源；已在 Foliate PDF、分页与固定版式模块上添加优化 |

## 原版与恢复

原软件和原书库数据应保存在自己的本地目录，并在更新前备份。源码仓库不包含本地书库、游戏收藏或个人 API 设置。

如需让原软件使用重构代码，在关闭软件后，先另行备份其 `resources/app.asar`，再用本项目的 `dist/app.asar` 替换它。这种方式保留原软件所在目录和现有绝对书籍路径。本次未执行该替换。恢复时放回备份的 `app.asar` 即可。

不要只复制新 `main.js` 到旧应用包：新的主入口依赖整个 `lib` 目录，界面也依赖新增脚本，应使用完整构建包。
