# 虚空图书馆阅读器 V3 修复说明

2026-10-12，基于 V2 源码继续修复。

## 1. 滚轮与放大滚动

- 修正嵌入式 Foliate 阅读器事件：**翻页模式**仍按页导航；**滚动模式**下流式电子书使用原生滚动，固定版式 PDF/FXL 放大后优先把滚轮传给阅读容器的纵向滚动位置。
- 固定版式容器采用 `safe center` 对齐，防止放大后的上部内容因居中和超出容器无法滚动到；切换 PDF 页重置纵向滚动位置。
- 单纯适配页面、没有纵向溢出的 PDF 在滚动模式下仍允许滚轮逐页移动。这一行为是为了避免滚轮完全无效，并非连续多页长卷渲染。
- 图片页缩放使用真实布局高度而不是只有 CSS transform，滚动模式下可使用滚轮浏览放大后的上下部分。

## 2. 导入后的书籍路径

- 书籍成功复制到数据目录 `books/<书籍ID>/...` 后，`library.json` 只存相对于应用**数据目录**的 `books/...` 路径。后端通过统一 `resolveBookPath()` 解析这些路径；封面提取、文件打开、PDF/EPUB 浏览、文本和图片清单、系统打开与显示文件位置都使用解析后的路径。
- 老版本的绝对路径仍可使用；如果数据目录整体迁移，旧路径已失效但本地 `books/<书籍ID>/...` 文件存在，自动定位并在下次读库时转成相对路径。
- 文件复制失败时报告跳过及错误原因，不再把原文件绝对位置静默保存成“已导入”。
- 整个书库不更换 ID、书架结构或阅读进度字段；原先引用外部绝对文件的记录保持兼容，不会强行把外部文件放到数据目录。

## 3. 测试与限制

- `npm run check`、`npm test`、`npm run build:portable` 通过；新增 PDF 放大滚动和迁移旧绝对路径测试。
- 构建 `app.asar` 时对所有 246 个打包文件作字节和 SHA-256 校验。
- 尚未在真实 Windows GUI 环境完成触控板、超大图片/扫描 PDF 人工测试；不宣称所有显示设备、PDF 缩放组合均已完全无卡顿。
- Windows 便携版解压后可直接试用；如果替换已有 `resources/app.asar`，建议先完整备份 `library.json`、`books` 目录和原包。相对路径以软件实际选择的**数据目录**为根（便携版优先 exe 所在目录，有权限问题时回退用户数据目录）。

注意：本轮所说的“书籍导入”是书库的导入文件/文件夹功能。整个软件的“导入备份 ZIP”没有重设计，也不能保证旧备份中包含未打包的书籍原文档。
