# 虚空图书馆阅读器 V4：跳页、书签、大小重置、首尾边界

更新：2026-10-12。基于 V3 源码继续修改；软件版本、书架目录与文件相对路径规则保持不变。

## 本轮变更

1. **输入页码跳转**：底栏的「页/%」输入改为「页码」，接受 1～当前总页数的正整数，并阻止超界与小数输入。PDF、固定版式及漫画文件/图片页采用实际页序号，TXT 按当前视窗滚动高度换算页号。EPUB/MOBI/FB2 为流式内容，没有固定的排版页数，使用 Foliate 的定长阅读位置编号（约每 1500 字节/位置）作为数字页号，内部再使用它的位置定位 API，**不代表印刷版页码，也不承诺严格等于排版后的视觉页号**。调整字体/窗口时，EPUB 的章节与 CFI 书签比数字页码更稳定。进度滑条仍可拖动，不再允许在输入框输入百分比。
2. **书签**：底栏「☆ 书签」可添加/取消当前位置；目录抽屉新增「书签」选项卡，支持列表查看、跳转和单条删除。保存在对应 `library.books[].bookmarks` 数组，位于 `library.json` 中，不另建数据目录。每条记录含 id、kind、page、cfi（电子书适用）、label 和 createdAt；EPUB/PDF 优先采用 CFI 定位，图片和 TXT 采用页号。对于TXT页码会随窗口尺寸和字体变化而变化。既有无 bookmarks 字段的记录自动视为空数组；没有清除旧记录。
3. **恢复默认大小**：底栏「重置大小」将图片缩放倍率重设为 1，TXT/流式书籍字号设为 18px，固定版式 PDF 恢复适应页面；之前的 A+/A- 功能仍可使用。
4. **首尾不循环**：图片页在首次、末次翻页时停留当前页面，不再使用 `% groups` 在首尾回环；单双页均适用。Foliate 的固定版式翻页本身具有边界保护，此外阅读器在第 1 页和末页禁止相应的反向/向前跳转；目录/页码可显式跳页。

## 数据兼容性

- 没有重置书架、存储位置、封面、阅读进度等字段。
- 新增 `bookmarks` 字段经前端数据规范化和后端 `persistLibrary()` 原样保存，随书库导入/导出保留。
- 继续兼容 V3 的 `books/...` 相对路径和旧版绝对路径修复规则。
- 不需修改或重新导入任何本地 `books` 文件。

- `npm run check`：通过。
- `npm test`：28 / 28 项 Node 回归、12 / 12 项 ZIP 回归、231 / 231 项界面回归通过。新测试覆盖页码跳转边界、PDF 页号、EPUB 定长阅读位置、书签增删和重开后持久化、图片单双页首尾停止、大小重置。
- `npm run build:portable`：成功，`app.asar` 对打包的 246 个源文件执行字节一致性和 SHA-256 比对。
- `npm run smoke`：**无法在当前 Linux 主机上运行 Windows PE `.exe`（EACCES）**，不属于 Windows 上的运行时错误结果；真实 Windows 图形环境未验收。

## 安装 / 回滚

- 先关闭软件，备份 `resources/app.asar`、`library.json` 及 `books` 目录；可直接替换 app.asar，或运行独立 V4 Windows 便携版。
- 单独便携版的实际数据目录可能不同；以软件设置里的数据目录为准。书签要保存，请从书库打开书籍，而非单纯从系统目录临时浏览。
- 若需回滚到 V3，新版 `library.json` 里多出的 `bookmarks` 字段可能不会被旧 UI 识别；阅读文件和旧进度不会因此丢失，建议备份以保证书签不被旧版覆盖。
